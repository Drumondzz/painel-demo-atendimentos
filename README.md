# Painel Demo de Atendimentos

Projeto simples de portfólio para demonstrar uma interface de organização de informações fictícias na área da saúde.

## O que o projeto faz
- Exibe uma tabela com registros de exemplo.
- Permite buscar por unidade ou serviço.
- Filtra registros por situação.
- Atualiza indicadores conforme os filtros aplicados.
- Adapta a visualização para telas menores.

## Tecnologias
- HTML
- CSS
- JavaScript puro

## Como visualizar
Abra o arquivo `index.html` em um navegador.

## Como publicar com GitHub Pages
1. Crie uma conta em https://github.com, se ainda não tiver.
2. Crie um repositório público chamado `painel-demo-atendimentos`.
3. Use **Add file > Upload files** e envie `index.html` e `README.md`.
4. Clique em **Commit changes**.
5. No repositório, abra **Settings > Pages**.
6. Em **Build and deployment**, selecione **Deploy from a branch**.
7. Escolha a branch `main` e a pasta `/(root)`, depois salve.
8. Aguarde a publicação. O GitHub mostrará o endereço do site nessa mesma seção.

## Aviso de privacidade
Todos os dados são fictícios. Não adicione informações reais de pacientes, credenciais, dados internos da Prefeitura ou capturas de tela de sistemas restritos.

## Limites
Este é um projeto de demonstração educacional, não um sistema clínico real e não deve ser usado para gerenciar atendimentos reais.
